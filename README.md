# Cinematic VFX Director Skill

通用影视 CG / AI 视频视觉特效导演 Skill。覆盖写实电影、日系半写实 CG、二维动漫、东方武侠仙侠、科幻机甲、奇幻、环境灾害、变形、梦境与非战斗演出。

> 当前状态：P0 基础文档与入口骨架；完整知识库、检索脚本和 QC 工具将分阶段实现，**目前不应视为功能齐全**。

## 核心理念
**特效必须服务镜头信息和动作因果**，并明确来源、触发、空间锚点、运动路径、受体/环境响应、消散状态。默认保持原剧本、人物身份、动作、构图和镜头原文不变，输出独立 VFX 建议；未经允许不代改全部镜头。

## 使用方式（P0 试用）
将 `SKILL.md` 提供给兼容 Agent Skill 的工具，并让其根据用户输入选择特效增强方案；P0 阶段仅提供基础指引，结构化知识库尚未落地。

示例：
- 「保持原提示词不变，为少女握住紫光剑的瞬间设计 L2 级激活特效，不能突然发射剑气。」
- 「写实电影中的暴风雨和积水反射应怎么处理？」
- 「检视一段科幻机甲变形镜头，找出特效与几何不一致的风险。」

## 设计决策
- 三轴模型：渲染媒介 × 题材 × 特效家族。
- 模型无关的 VFX Effect Card 是核心中间表示。
- Python 标准库离线检索与数据校验（P2）。
- 多镜头支持状态延续与解耦两种模式。
- 不默认引入剑气、爆炸、光环或重度粒子。

个人使用不自动豁免第三方许可证；公开仓库内复用内容需保留必要署名和授权。
