# VFX 特效因果构建语法（P1）

本项目的工作对象是**视觉信息**，不是“越亮越好”。主问题：观众需要在这一节拍看懂什么？若特效只增加花哨，不承担视觉信息，优先减轻或移除。

## Effect Card 因果链
`intent → source/owner → trigger → anchor → form/material → motion/path → operation/contact → receiver/environment/light response → peak → decay/residue → endpoint`。
每一段可根据可见内容省略，不允许凭空补出原剧情没有的超能力或打斗动作。

| 部分 | 应回答的问题 | 常见错误 |
|---|---|---|
| intent | 表示激活/速度/触碰/威胁/空间变化/气象？ | 只说“酷炫能量” |
| source/owner | 是武器、人、环境、装置、法阵还是未知来源？ | 粒子乱飘、没有归属 |
| trigger | 哪个可观察事件使其启动？ | 人未握剑就提前爆闪 |
| anchor | 锚定剑刃、掌心、接触点、天气区域或空间边界？ | 漂移、越位、错层 |
| form/material | 光带/流体/碎片/尘土/能量体的形状和材质？ | 所有招式都是同一团光 |
| motion/path | 沿何路径、方向、尺度变化？ | 不符合武器轨迹 |
| operation/contact | 真正作用到什么？ | 未命中却有打击火花 |
| response | 受体、衣物、光照、地面、天气怎么反应？ | 贴图感与物体无互动 |
| decay/endpoint | 怎样结束及留存结果？ | 效果突然消失或无限持续 |

## 三层视觉职责
- Primary：主形状/事件信息；每节拍只保留一条核心信息。
- Secondary：接触、受体、材料、环境及互动光照证据。
- Tertiary：少量空气、残留粒子、光雾等节制装饰。
- 多特效并存要明确先后和大小，不让所有层同时达到峰值。

## 优先级、质量和冲突
- 固定镜头/动作/人物信息不得由 VFX 取代。
- 效果有一个主要 `family`，允许辅助家族，不强迫双元素组合。
- 现实写实与超自然幻想分别遵守所在世界内的因果；不是“真实物理强加于魔法”。
- 对不存在的命中、攻击、崩塌或毁灭不得主动加效果。
- 只用人物动作自然带动的摄影/运动，不主动改机位。
- 遇到“额外效果”可能改变世界观时，给可选增强建议，不当作强制输出。

## 输出模板
1. 原文保留（只在用户提供原文时）。
2. 作用节拍及其观看重点（简短）。
3. 最小 `VFX delta`（可拼接入提示词，正面描述优先）。
4. 关键约束与禁加项。
5. 用户明确要求时再提供 Effect Card、整合版和 QC。

## 示例（不新增战斗）
女主右手握紧原有悬浮剑柄 → 微弱紫光沿**原剑刃**集中并掠过 → 两三束微小粒子靠近剑身散开 → 光照映到握剑手指、袖口和脸缘 → 逐渐恢复安静持续的基础辉光。全程不拔剑、不挥砍、不产生独立剑气或冲击波。
