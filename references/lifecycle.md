# VFX 生命周期、动作绑定与跨镜头状态（P1）

## 可选事件阶段
`idle`（基础状态）、`anticipation`（预兆）、`charge`（蓄力）、`activation`（激活）、`release`（释放）、`propagation`（扩散/传播）、`contact`（接触/作用）、`response`（受体/环境反馈）、`decay`（衰减）、`residue`（残留）、`settled`（稳定结束）。
这些不是必须按顺序出现的十一步；天气可无蓄力，机械变形可能有多个局部阶段，静态图只描述单个决定性阶段。

## 同步规则
- `trigger` / `onset_anchor` 应采用可见动作或环境状态：`on-grip`、`on-contact`、`on-footfall`、`on-mechanical-lock`、`on-rain-intensifies`、`on-formation-complete` 等；时长明确时才指定秒数。
- “蓄力”的粒子向内汇聚，“释放”的能量离开源头或转换状态；特效不能反向偷换因果。
- 碰撞类在接触帧出现峰值；可以有接触前的预兆，但不能提前出现接触反馈。
- 对于短视频，不要求为了完整生命周期硬塞所有阶段；以当前镜头能看见的阶段为准。
- 区分持续型（雨、云、辉光）、事件型（激活、碰撞）、形变型（机械展开）、扩散型（烟雾、涟漪）各自的起止逻辑。

## 空间与画面
定义世界/局部锚点、屏幕前后层次、方向性、比例变化、遮挡、投射到附近材质的光照。主物体受风向、潮湿、重力、镜头景深影响应与特效保持一致。若无法观察到某物理信息不应编造。

## 分镜之间的连续状态
每个镜头可携带：
```json
{
  "effect_state_in": {"id":"blade-violet","status":"idle-glow","color":"violet"},
  "effect_state_out": {"id":"blade-violet","status":"active-glow","color":"violet"},
  "continuity_mode":"continue"
}
```
- `continue`：沿用上一镜头中同一效果的核心属性，允许镜头视觉表现不同。
- `reset`：明确跳时、切换地点或重新设置效果状态。
- `independent`：不要求跨镜头追踪，适合无关混剪镜头。
- 用户的剧本决定连接还是解耦，不能为了延续感强制增加情节。

## 反例
1. 两人刀刃未触碰，画面已出现大量金属碰撞火花（错误提前接触）。
2. 上一镜紫色附魔，下一镜无理由改蓝色（连续性丢失）。
3. 已有雾气从房间漂到室外，没有任何气流或边界说明（空间原因缺失）。
4. 本来普通挥剑的拖尾变成独立追踪敌人的飞弹（擅自升级世界观）。
